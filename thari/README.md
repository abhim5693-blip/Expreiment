# Thari: handwoven silk

A concept brand site for a Kanchipuram silk saree label. Plain HTML, CSS and JavaScript, with no build step.

Includes the "on the rail" wardrobe: sarees hang on a clothes rail, turn toward you on hover, and open a product sheet on click. Changing the colour in the sheet also changes the saree on the rail.

## Run locally

```
node serve.mjs
```

Then open http://localhost:5321.
